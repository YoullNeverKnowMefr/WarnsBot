# Жалобщик-бот (Telethon .session)

Управляющий Telegram-бот + воркеры на user-аккаунтах (Telethon).

## Что умеет

- Жалобы на **бота** и на **последнее сообщение** бота (разные тексты)
- Цикл: аккаунты → целевые боты → `/start` + приветствие → N жалоб → пауза → повтор раундов
- Меню: статусы, логи, добавление/удаление аккаунтов и целевых ботов
- Проверка спамблока через @SpamBot
- Контроль удаления целевых ботов (2ч / 5ч / 12ч / 24ч) и счётчик за 3 суток
- Тексты жалоб: файлы или загрузка через меню (можно 300+)

## Установка

```powershell
cd D:\tgbots\jalobyBot
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
copy .env.example .env
```

Заполните `.env`:

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | токен управляющего бота от @BotFather |
| `API_ID` / `API_HASH` | с https://my.telegram.org/apps |
| `ADMIN_IDS` | ваш Telegram user id (через запятую) |

## Запуск

```powershell
.\.venv\Scripts\python main.py
```

## Меню бота

1. **Аккаунты** → `.session` **или по номеру** (код + 2FA)
2. **Целевые боты** → список `@bot1 @bot2` → отметьте галочками
3. **Тексты жалоб** → при необходимости свои (к «Жалоба номер N»)
4. **Старт кампании**

Схема (как в ТЗ/видео): `/start` → ответ → **3 жалобы на бота** (документы / наркотики / мошенничество) + **3 на сообщение** с рандомным «Жалоба номер N» → пауза **5 мин** между аккаунтами → повтор раунда через **~20 мин**, всего **5 раз** → отчёт удаления через **2/5/12/24 ч**. Аккаунты со спамблоком пропускаются.
## Формат аккаунтов

В боте: **Аккаунты** →
- `.session` (Telethon)
- **tdata (zip)** — архив папки Telegram Desktop `tdata`
- по номеру телефона

Перед tdata **закройте Desktop**. Passcode (если есть) — в подписи к zip.

Зависимости для tdata:

```powershell
.\.venv\Scripts\pip install -r requirements.txt
```

Офлайн-конвертер: папка `tdata_converter/`.

Логи: консоль + `data/logs/bot.log` + кнопка «Логи» в боте.
